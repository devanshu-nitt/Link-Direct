1. Wrong address picked — if your PC has more than one network adapter (WiFi + Ethernet + VPN, etc.), the address shown may not be the hotspot-facing one. Check the "Multiple network adapters detected" box above and try each address listed there.

2. Windows Firewall — the first time you run this, Windows may block it, especially since hotspot networks are often set to "Public." Re-run start-windows.bat and approve the permission popup if one appears.

3. Faster transfers (5GHz) — whichever device is hosting the hotspot, check its hotspot settings for a band option (e.g. "AP Band: 5GHz" on Android). Both devices must support 5GHz for this to work, and it usually gives noticeably faster transfer speeds than 2.4GHz once connected.

4. Double-check the port — the address must include :8080 at the end, exactly as shown above.
